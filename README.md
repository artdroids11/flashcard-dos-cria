# Mitos e Lendas do Brasil

Este projeto é uma página web feita com HTML e CSS, usando flashcards interativos sobre mitos e lendas do Brasil.

## Tema

O site apresenta personagens e histórias do folclore brasileiro, como Saci, Curupira, Iara, Boitatá, Cuca, Boto-cor-de-rosa e outras lendas populares.

## Como funciona

Cada card mostra uma informação na frente. Ao passar o mouse sobre o card, ele vira e apresenta uma explicação mais completa sobre o tema.

## Tecnologias usadas

* HTML
* CSS

## Objetivo

O objetivo do projeto é praticar a criação de páginas web com HTML e CSS, utilizando cartões interativos para organizar informações de estudo.
